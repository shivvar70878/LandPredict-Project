GitHub Deployment Guide

Instructions for deploying this platform to GitHub Pages and hosting the FastAPI backend.

1

Push Repository to GitHub

Initialize your GitHub repository and push the commit from your terminal:

git remote add origin https://github.com/<YOUR-USERNAME>/<YOUR-REPO-NAME>.git
git branch -M main
git push -u origin main
2

Enable GitHub Pages (Static Frontend Hosting)

GitHub Pages hosts the interactive web portal for free directly from your repository:

  1. Go to your repository on GitHub.
  2. Click Settings → Pages (in the left sidebar).
  3. Under Build and deployment:
    • Source: Deploy from a branch
    • Branch: main
    • Folder: / (root)
  4. Click Save. In 1–2 minutes, your live URL will be ready at: https://<username>.github.io/<repo-name>/.
3

Client-Side Fallback & Offline Demonstration

When hosted on GitHub Pages without a backend server, the platform automatically switches to Static Demonstration Mode. It seamlessly loads 303 national corridor records directly from frontend/land_acquisition_dataset-5.csv, allowing judges and evaluators to test all filters, maps, and charts without installing Python or MySQL!

4

(Optional) Deploy FastAPI Backend to Free Cloud (Render / Railway)

To run the live Python AI model and MySQL database in production:

# Start Command for Render.com / Railway.app:
uvicorn backend.server:app --host 0.0.0.0 --port $PORT

Set your cloud backend URL in frontend/sharedAuth.js:
window.API_BASE_URL = "https://your-backend.onrender.com";
